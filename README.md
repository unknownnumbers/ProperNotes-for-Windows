## English (en)

This branch contains the native Windows host and its build recipe. It is not the complete PDF application or a ready-to-run portable package. The workflow compiles and packages the host without launching the application or running tests. Read [the build instructions](cloud-build/CLOUD-BUILD.md) and [host reference](windows-host/README.md). Runtime and device acceptance are not yet complete.
